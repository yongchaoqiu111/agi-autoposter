## 🌟 项目定位

AGI-AutoPoster 是基于 **原子化三层架构** 构建的 AI 自动化内容发布系统。

代码极简，但架构完整。

##  核心架构（全书灵魂）

```
一切皆原子
三层彻底解耦
满意即固化，不再探索
人类主导进化，AI 辅助执行
```

### 三层严格解耦（工业级标准）

**调度层（AI 决策）**
- 大模型只做任务规划、ID 选择、指令下发
- 不执行、不探索、不耗冗余 Token

**执行层（固定脚本）**
- 无智能、无 AI、纯确定性运行
- 极快、极稳、极低成本

**监督层（事实记录）**
- 只做审计、结果校验、失败隔离
- 不干预、不阻塞、不嵌套
