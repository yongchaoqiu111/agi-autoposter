## 架构特点 / Architecture Features

- **稳定优先 / Stability First** - 工业级系统需要确定性，而非可能性
- **可控执行 / Controlled Execution** - 三层结构体确保任务可靠执行
- **原子化组合 / Atomic Composition** - 灵活组合，适应不同场景
