##  核心架构 | Core Architecture

| 中文版 | English Version |
|:---|:---|
| **调度层（AI 决策）**<br>• 大模型只做任务规划、ID 选择、指令下发<br>• 不执行、不探索、不耗冗余 Token | **Scheduling Layer (AI Decision)**<br>• Large models only do task planning, ID selection, command dispatch<br>• No execution, no exploration, no redundant token consumption |
| **执行层（固定脚本）**<br>• 无智能、无 AI、纯确定性运行<br>• 极快、极稳、极低成本 | **Execution Layer (Fixed Scripts)**<br>• No intelligence, no AI, purely deterministic operation<br>• Extremely fast, extremely stable, extremely low cost |
| **监督层（事实记录）**<br>• 只做审计、结果校验、失败隔离<br>• 不干预、不阻塞、不嵌套 | **Supervision Layer (Fact Recording)**<br>• Only auditing, result verification, failure isolation<br>• No intervention, no blocking, no nesting |
