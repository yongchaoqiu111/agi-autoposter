    第 7 章 原子的组合规则¶

    7.1 为什么需要组合规则¶

    原子很小，但世界很大。

    一个原子只能做一件事（比如发一条抖音）。但真实业务需要做很多件事（比如"早上 8 点发抖音，9 点发 Facebook，10 点发 X"）。

    组合规则定义了：如何用小原子组成大系统。

    7.2 三层组合¶

    7.2.1 原子 → 分子¶

    多个原子可以组合成一个分子。

    分子是一个"业务单元"：

    • 分子 A："早间推广" = 抖音原子 + Facebook 原子 + X 原子
    • 分子 B："午间推广" = 抖音原子 + TikTok 原子
    • 分子 C："晚间推广" = 全平台原子

    分子不新建"超级原子"，分子只是原子的调度计划。

    7.2.2 分子 → 系统¶

    多个分子可以组合成系统。

    系统 = 全天推广计划 = 分子 A（早间） + 分子 B（午间） + 分子 C（晚间）

    7.2.3 系统 → 生态¶

    多个系统可以组合成生态。

    生态 = 内容生产系统 + 发布系统 + 数据采集系统 + 硬件控制系统

    7.3 组合规则一：任意内容 + 任意调度 + 任意执行 = 新事件¶

    这是最核心的组合规则。

    内容层、调度层、执行层是完全解耦的，你可以任意搭配：

    内容 调度 执行 结果
    内容 A（文案库） 调度计划 1（每天 8 点） 抖音执行器 抖音早报
    内容 A（文案库） 调度计划 1（每天 8 点） Facebook 执行器 Facebook 早报
    内容 A（文案库） 调度计划 2（每周一） X 执行器 周报
    内容 B（图库） 调度计划 3（即时） 抖音执行器 即时发图

    规则：任意组合，不需要预先定义。

    7.4 组合规则二：组合后的系统保持原子特性¶

    这是最重要也最容易被忽略的规则。

    组合不会破坏原子特性。

    原子特性 组合后是否保持 说明
    不链接 ✅ 保持 原子之间仍无直接连接
    不通信 ✅ 保持 原子之间仍不发消息
    失败隔离 ✅ 保持 一个原子失败，不扩散
    独立部署 ✅ 保持 可以单独升级一个原子

    这意味着：无限嵌套，复杂度不会爆炸。

    7.5 组合规则三：组合是"调度"，不是"继承"¶

    这是最容易踩的坑。

    • ❌ 错误理解：组合 = 创建新的"超级原子"
    • ✅ 正确理解：组合 = 定义原子的执行顺序和时间

    组合不创建新代码，只创建新配置。

    {
  "molecule": "morning_broadcast",
  "schedule": "0 9 * * *",
  "atoms": [
    {"type": "douyin", "content_id": 5, "image_id": 3},
    {"type": "facebook", "content_id": 5, "image_id": 3},
    {"type": "x", "content_id": 5, "image_id": 3}
  ]
}

    这是一个"分子"的定义：

    • 不写新代码
    • 只配置已有原子的调用方式
    • 分子可以被调度，但不能被"继承"

    7.6 硬件扩展规则¶

    这套组合规则同样适用于硬件。

    7.6.1 硬件原子组合¶

    分子："生产任务" = 机械臂原子（抓取） + 传送带原子（移动） + 视觉检测原子（质检）

    7.6.2 硬件与软件的组合¶

    分子："智能营销" = 抖音原子（发视频） + 数据采集原子（收集反馈） + 硬件原子（打印工单）

    软件原子和硬件原子可以自由组合，架构不变。

    7.7 组合的边界¶

    组合可以无限嵌套，但有两条边界不能跨越：

    7.7.1 原子之间不直接调用¶

    ❌ 错误：原子 A → 直接调用 → 原子 B
✅ 正确：调度层 → 调度原子 A → 调度原子 B

    7.7.2 原子不依赖其他原子的结果¶

    一个原子的执行，不应该依赖另一个原子的结果。

    如果需要依赖，应该：

    1. 原子 A 执行 → 结果写入监督层
    2. 调度层查询监督层
    3. 调度层决定是否调度原子 B

    依赖关系从"原子间"上移到"调度层"。

    7.8 组合的示例：从单次发帖到全天自动化¶

    第 1 层：原子

    原子 A：发一条抖音（内容 ID 5，图片 ID 3）
原子 B：发一条 Facebook（内容 ID 5，图片 ID 3）
原子 C：发一条 X（内容 ID 5，图片 ID 3）

    第 2 层：分子

    分子"早间推广"：原子 A + 原子 B + 原子 C
调度时间：每天 9:00

    第 3 层：系统

    系统"全天推广"：
- 分子"早间推广"（9:00）
- 分子"午间推广"（13:00，内容 ID 6）
- 分子"晚间推广"（19:00，内容 ID 7）

    第 4 层：生态

    生态"全链路营销"：
- 系统"全天推广"
- 系统"数据采集"（收集互动数据）
- 系统"智能分析"（生成新内容建议）
- 系统"硬件打印"（打印订单工单）

    每一层都是由下一层原子组合而成，架构模式完全一致。

    7.9 本章小结¶

    组合规则定义了这套架构的扩展方式：

    规则 含义
    规则一 任意内容 + 任意调度 + 任意执行 = 新事件
    规则二 组合后的系统保持原子特性
    规则三 组合是"调度"，不是"继承"

    一套组合规则，从单次操作延伸到全天自动化，从软件延伸到硬件，从应用延伸到生态。
