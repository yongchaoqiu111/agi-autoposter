# 第 16 章 如果需要探索能力怎么办

---

## 在稳定架构上叠加探索能力

这套架构的核心是"稳定"，但不意味着不能"探索"。

探索能力可以通过以下方式叠加：

---

## 1. 叠加 A/B 测试模块

在调度层之上，增加 A/B 测试模块：

```text
调度层 → A/B 测试模块 → 执行层
```

- A/B 测试模块负责分配流量
- 调度层负责执行具体任务
- 监督层记录 A/B 测试结果

---

## 2. 人工引入新变量

探索不需要自动，可以人工：

- 人工添加新平台
- 人工添加新内容
- 人工调整调度策略

系统执行，人工探索。

---

## 3. 上层叠加探索型 Agent

在三层结构体之上，可以叠加一个探索型 Agent：

```text
探索型 Agent（上层）
    ↓
三层结构体（下层，稳定执行）
```

- 上层负责探索、实验、优化
- 下层负责稳定执行
- 两层解耦，互不影响

---

## 4. 明确授权探索模式

监督层支持"探索模式"，但需要明确授权：

- 默认关闭
- 需要人工开启
- 探索结果不会自动采纳

**探索是选项，不是默认行为。**

---

## 本章小结

| 探索方式 | 说明 |
|----------|------|
| A/B 测试 | 在调度层之上叠加 |
| 人工引入 | 人工添加新变量 |
| 上层 Agent | 探索型 Agent + 稳定执行层 |
| 探索模式 | 监督层支持，需授权 |

**稳定是基础，探索是选项。先稳定，再探索。**
