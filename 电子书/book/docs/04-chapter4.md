# 第 4 章 三层结构体定义

---

## 4.1 内容层：只输出 ID

内容层不输出"内容"，只输出"内容 ID"。

为什么？因为大模型不能编造内容。它只能从已有的内容库里选。

所以内容层的职责是：

- 存储内容（文案、图片、视频）
- 为每个内容分配唯一 ID
- 对外只暴露 ID

大模型看到的是："文案 ID 5"，不是"一段关于 AI 的文案"。

**不给编造空间。**

---

## 4.2 调度层：只选 ID

调度层由大模型驱动，但它只做一件事：选择 ID。

- 它不编造平台，只从已有平台列表里选
- 它不编造文案，只从已有内容 ID 里选
- 它不编造时间，只从设定好的时间段里选

**不给幻觉机会。**

---

## 4.3 执行层：只认参数

执行层不判断"该不该发"，只负责"怎么发"。

它接收参数：平台、文案 ID、图片 ID。然后登录、发帖、返回结果。

它不判断：这个平台今天能不能发？这个文案是不是违规？这个时间合不合适？

**只认参数，不判断对错。**

---

## 4.4 监督层：只记录真相

监督层不干预执行，不修改任务，不做决策。

它只做三件事：

1. 记录所有任务的状态（成功、失败、超时）
2. 记录所有任务的结果（URL、错误信息）
3. 提供查询接口（供调度层学习）

**不玩花样，只说真话。**

---

## 本章小结

| 层级 | 职责 | 核心原则 |
|------|------|----------|
| 内容层 | 存储内容，输出 ID | 不给编造空间 |
| 调度层 | 大模型选择 ID | 不给幻觉机会 |
| 执行层 | 执行具体操作 | 只认参数，不判断对错 |
| 监督层 | 记录状态，提供查询 | 只说真话 |

三层结构体 = 内容层 + 调度层 + 执行层 + 监督层
