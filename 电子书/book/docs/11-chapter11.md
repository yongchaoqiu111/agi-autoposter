# 第 11 章 能力边界

---

## 11.1 ✅ 能做什么

- 稳定执行任务
- 并发调度（分身机制）
- 层层过滤幻觉
- 失败重试、超时强杀
- 全程可观测、可追溯

---

## 11.2 ⚠️ 有限能力：自动发现更优策略

如果开启探索模式，系统可以尝试新组合。但"发现更优策略"需要人工判断或 A/B 测试确认。

系统不会自动把"尝试成功"当作"新默认策略"。

---

## 11.3 ❌ 不做什么

- 无中生有的创新（不负责写新文案、设计新图片）
- 自动进化（不会自己改代码、改架构）
- 跨原子的自动优化（原子之间不通信）

---

## 本章小结

| 能力 | 状态 |
|------|------|
| 稳定执行 | ✅ 完全支持 |
| 并发调度 | ✅ 完全支持 |
| 幻觉过滤 | ✅ 完全支持 |
| 自动发现更优策略 | ⚠️ 有限支持 |
| 无中生有创新 | ❌ 不支持 |
| 自动进化 | ❌ 不支持 |

**这套架构的定位：稳定执行，不是自动进化。**
